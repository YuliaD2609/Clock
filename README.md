Tracker di scadenze. Inserimento di scadenze con nome e luogo e relativo timer a schermo intero per massimizzare la produttività. Completamente personalizzabile.

## 🛡️ Sicurezza e Monetizzazione
Per motivi di sicurezza, alcuni file sensibili relativi alla logica di sblocco premium e alla generazione dei codici sono stati esclusi dal repository tramite `.gitignore`.

Se desideri compilare il progetto autonomamente, dovrai ricreare i seguenti file partendo dai template forniti:

1. **`SecretKeys.java`**:
   - Copia `SecretKeys.java.example` e rinominalo in `SecretKeys.java`.
   - Inserisci la tua chiave segreta personale.
   
2. **`AdminActivity.java`, `PremiumHelper.java` e `activity_admin.xml`**:
   - Copia i file `.example` corrispondenti e rimuovi l'estensione `.example`.
   - Questi file sono necessari per la compilazione ma la logica reale è riservata allo sviluppatore.
